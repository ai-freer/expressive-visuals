# 从定稿效果图探索三维还原方法

先打开当前生效的原图、已有风格定义和最新实物，确认用户要看的交付物及实际观看条件。只有单图时，可从主机位开始，未画出的背面和深度属于推定。评审只交分析；要求整景成图时，局部实验和素模都是中间步骤。

**从整图选择问题。** 把原图和当前画面调到相同裁幅和展示尺寸，先缩小，再回到目标观看尺寸。问：如果抹去表面纹理，哪处仍然一眼不像？沿画面指出前中远景的主体轮廓、可见立面的宽度比例、遮挡先后、承重连接和本该留空的位置。对结构本身不熟时，查同类实物或构造资料，先弄清部件怎样相接。即使有同名模型，也要核对它在画面中发挥的作用。若轮廓已准而体积或气氛仍错，转查明暗、透视浓淡和材质，不强制一律先重建模型。

**先区分解释，再选实现。** 先描述原图里可见的现象，再决定由几何、表面颜色、光照或几者共同实现。如果两条路线在原机位都说得通，就找一个会让它们给出不同预测的观看条件。例如水彩晕边可以画在物体表面，也可以随明暗交界生成：固定镜头和物体，移动光源，前者留在原处，后者随阴影移动。按作品需要哪种行为选择路线；若单张参考图不能判定，就把选择记为假设。固定机位下两者都满足目标时，选成本较低的方案即可。

**每轮只追一个会改变下一步的判断。** 动手前说清「我认为差距来自 X；保持什么不变，看哪种现象；如果看到 Y，就改走哪条路」。选最便宜的有效对照：例如固定机位切换材质，以素模或剪影区分建模和照明问题；固定模型与光线比较颜料分布；以低角度、移灯或运动区分表面颜色与真实起伏。测试条件按用户用途选，固定插画机位不必证明全周可看。多项一起改只能评价组合效果，不据此认定某一个因素有效。

**回看后决定保留、修正还是换路。** 把小样放回整图原来的占比。局部更精致而整图的主要差距还在，停止细调，重新选问题；笔触方向正确但明暗块错误，就改颜料分布或绘制方式。第一机位相似、横移即穿帮，则检查遮挡、背面覆盖或所选表示方法。用到原图像素时说明哪些是取样、投射或延展，哪些是独立建模或生成；一次近似不证明方法可迁移。用户的新纠正纳入当前迭代，不让用户代做每轮判断。

**回到约定交付物。** 局部研究交原图裁片、受控对照和此次取舍；完整材质渲染要把改动整合进实际场景，打开并看最终成图，对比整体和最有辨别力的局部。用户要可编辑或可游玩版本，则在对应工程或实际游戏镜头验证。按请求给出能看的结果、所需源文件和最明显的剩余差距。整景尚未渲染时，继续已授权的工作；无法继续才说明实际阻碍。不要用轮数、模型清单、贴图已打包或后续计划替代成图。

**验证技能能否迁移时，做一次无路线提示的试用。** 选一张 Agent 没做过、关键视觉特征也不同的效果图，只提供目标、使用条件和必要约束。制作前由 Agent 自己指出最关键的特征，记录候选解释及其不同预测。完成后一起看三样实物证据：抓住该特征的小样、能暴露方法局限的对照、由对照支持的保留／修正／换路决定。判断依据是 Agent 能否在用户纠正前选对问题，并凭结果作出取舍；原方法经受住对照也算有效判断。若关键问题或技术路线由用户中途指出，记为有指导试用。单次结果只说明对该案例的表现。
