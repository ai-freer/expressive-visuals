# 表现力与意境 · Expressive Visuals

[English](README.md) | [中文](README_CN.md)

用于以视觉表达为核心的作品（网页、交互作品、3D 场景与模型、图像、视频、动画等）的启发式创作 Skill。

沿内容、形式与观看三个方面提示：从原著、资料或概念中的价值、世界观、关系与意境出发，寻找表达的切入点与变化轴，再考虑艺术风格、形态与空间、光影与氛围、镜头语言、注意力、观看关系和时间体验，最后让判断落到可见的结果上。参考研究与实际观看也可以带来新的理解。

这些开放问题用于拓宽创作选择。按任务选用，无需逐项回答、全部覆盖或额外提交分析文档；保留模型自身的理解与创作判断，不预设统一风格或模型专属方法。

## 三篇 3D 指南怎么选

海报、排版网页、影片等作品可以直接使用[通用创作提示](SKILL.md#prompts-to-revisit-while-creating)。遇到下列问题时再选相应指南，每篇都可独立使用。

| 指南 | 什么时候单独用 |
|---|---|
| [从概念图还原 3D](references/concept-to-3d.md) | 要在首次渲染前规划怎样还原定稿，或诊断已有渲染哪里不像、为什么不像。可继续使用 Blender 等既定工具。 |
| [代码驱动的 3D 制作](references/code-driven-3d.md) | 要用代码塑造物体、布光或搭建原创场景。主要工具是 Three.js，交付可以只是一张静帧。浏览器交付与成本也在这篇。 |
| [代码驱动的 3D 互动](references/code-driven-3d-interaction.md) | 要判断观众的行动能让人感知或改变什么。用占位形体或已有模型都能试；同样的动作如果在 2D 网页上就能成立，也可以借用这篇。 |

按定稿用代码建模，合用**还原＋制作**；从零做可操作的机械装置，合用**制作＋互动**。如果场景资产已经齐备，只要求开场忠于原画，再让观众探索，就用**还原＋互动**。只有既要对准定稿、又要用代码搭景，还要设计观众的行动时，才需要三篇合用。[主入口](SKILL.md#choosing-a-3d-approach)给出了每种组合的使用示例。

## 迁移能力评估

**跨风格还原。** 这项迁移能力仍待验证。有辨别力的试验应使用视觉特征不同的陌生效果图，只提供目标、观看条件和必要约束，不提示技术路线。制作前，由 Agent 识别关键视觉特征，提出会产生不同预测的候选解释。证据包括抓住该特征的渲染小样、暴露方法局限的对照，以及由结果支持的保留、修正或换路决定；对照支持原方法时，保留同样是有效判断。能否在用户纠正前选对问题，与最终画面同样重要；用户中途给出关键诊断或路线的试验属于引导试验。单个结果只能说明该案例的表现，不能证明通用能力。

**用代码制作原创模型。** 给出一次具体改稿，例如加宽一道拱门，同时保住两侧开间和预定视角。比较哪些关系随之改变、哪些被破坏，以及需要多少返工。

**互动。** 让没看过作品的人直接上手，不先演示。观察对方能否发现操作、感知回应，并再次做出同样的结果。输入回放可以验证规则，但不能证明观众看懂了。互动指南尚未经过实际制作试验。

以上是评估方法。要把改进归因于这个 Skill，应在相同任务、工具、模型和预算下比较使用与不使用它的结果；两组获得的人工提示也应相当，并如实记录。

## 使用

将本仓库作为 `expressive-visuals` 技能目录安装到支持 `SKILL.md` 的客户端。在支持按名称调用的客户端中，可用 `$expressive-visuals`。具体发现与加载方式由客户端决定。
